# Carpeta de imágenes del sitio

Colocá aquí todos los logos, ilustraciones y recursos visuales generales de Coordina.

Nombres sugeridos:

- `logo-coordina.svg`: logo principal.
- `logo-coordina-blanco.svg`: logo para fondos oscuros.
- `flyer-coordina.webp`: flyer o imagen promocional.
- `mockup-celular.webp`: imagen del teléfono o aplicación.
- `icono-asistencia.svg`: ícono relacionado con asistencia.

Formatos recomendados:

- SVG para logos e íconos.
- WEBP o PNG para imágenes con transparencia.
- JPG para fotografías.

Los códigos QR deben mantenerse separados en la carpeta `qr/`.
