# Carpeta de códigos QR

Colocá aquí los archivos que querés mostrar en la página pública:

- `qr1.svg` o `qr1.png`: QR informativo / presentación.
- `qr2.svg` o `qr2.png`: QR para registrar asistencia.

La web intenta cargar primero estos archivos. Si no existe ningún QR seleccionado, la página pública muestra el estado `QR no configurado` y no genera un código automáticamente.

También podés administrar reemplazos desde `admin.html`. En esta versión estática, las imágenes subidas desde el navegador se guardan en el almacenamiento local de ese navegador.

Los logos, flyers e imágenes generales del sitio deben colocarse en la carpeta `img/`.
